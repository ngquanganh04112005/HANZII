# Hán Ngữ Tu Tiên

Create a high-fidelity desktop game UI concept for “Hán Ngữ Tu Tiên”, a 2D chibi xianxia language-learning RPG inspired by the atmosphere of A Record of a Mortal’s Journey to Immortality and Sword of Coming.

Focus ONLY on the main combat screen. Use a restrained Chinese fantasy art direction: misty mountains, ancient stone paths, bamboo, muted blue-gray and jade-green colors, elegant sword energy, subtle talisman patterns, and refined Chinese-inspired UI frames.

Place a small chibi cultivator in dark blue robes on the left, facing a cute but mystical monster on the right that is running toward the player. Display a large simplified Chinese vocabulary prompt above the monster. Place a prominent text input area at the bottom for Chinese IME typing.

Show a flying sword and a magical hand-seal attack as visual examples of successful answers. Include compact health bars, cultivation rank, score, and a small vocabulary progress indicator.

The result must feel like a polished indie game screenshot, not a dashboard or a generic language-learning website. Use original character designs, cohesive illustrations, readable typography, and detailed atmospheric backgrounds. Prioritize visual quality over implementing gameplay logic. Make the layout responsive and keep the combat area dominant.
